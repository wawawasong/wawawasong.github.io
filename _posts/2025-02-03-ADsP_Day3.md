# 분석 대상과 그 방법에 따른 4가지 분석 주제
- 최적화 = 분석 대상 O, 분석 방법 O
- 솔루션 = 분석 대상 O, 분석 방법 X
- 통찰 = 분석 대상 X, 분석 방법 O
- 발견 = 분석 대상 X, 분석 방법 X

# 목표 시점별 분석 기획
- 과제 중심적인 접근 방식 = 빠르게 해결하는 것이 목적
  (Speed&Test, Quick&Win, Problem Solving)
- 장기적인 마스터플랜 방식 = 지속적으로 해결하는 것이 목적
  (Accuracy&Deploy, Long Term View, Problem Definition)

# 분석 기획 시 고려사항
- 가용 데이터 고려
- 적절한 활용 방안과 유스케이스의 탐색
- 장애요소에 대한 사전 계획 수립

# 분석 방법론의 구성
- 상세한 절차(Procedure)
- 방법(Method)
- 도구와 기법(Tools & Techniques)
- 템플릿과 산출물(Templates & Outputs)

# 기업의 합리적인 의사결정 방해요소
- 고정 관념
- 편향된 생각
- 프레이밍 효과(동일한 사건, 상황을 두고 개인의 판단이나 선택이 달라질 수 있는 현상)

# 분석 방법론의 생성 과정
- 암묵지 -(형식화)→ 형식지 -(체계화)→ 방법론 -(내재화)→ 암묵지

# 분석 방법론이 적용되는 업무 특성에 따른 모델
- 폭포수 모델 = 단계를 거쳐 순차적으로 진행, 하향식
- 프로토타입 모델 = 사용자 중심 개발 방법
- 나선형 모델 = 위험요소를 사전에 제거한다는 것에 초점
- 계층적 프로세스 모델 = 단계, 테스크, 스탭으로 구성

# 빅데이터 분석의 계층적 프로세스
- 단계(Phase) = 프로세스 그룹을 통해 완성된 단계별 산출물 생성, 비전 관리 등을 통한 통제 필요
- 테스트(Task) = 단계를 구성하는 단위 활동, 물리적/논리적 단위로 품질 검토의 항목
- 스탭(Step) = WBS의 워크패키지에 해당, 입력 - 처리/도구 - 출력 자료로 구성된 단위 프로세스

# KDD 분석 방법론
- Knowlege Discovery in Database, 데이터로부터 통계적 패턴이나 지식을 찾기 위해 정리한 데이터 마이닝 프로세스
- 데이터 마이닝, 기계학습, 인공지능, 패턴인식, 시각화에 응용 가능

[5단계 프로세스]
데이터셋 선택 → 데이터 전처리 → 데이터 변환 → 데이터 마이닝 → 해석과 평가

# CRISP-DM 분석 방법론
- KDD보다 세분화

[4레벨, 6단계 프로세스]
단계, 일반화 태스크, 세분화 태스크, 프로세스 실행
업무 이해 → 데이터 이해 → 데이터 준비 → 모델링 → 평가 → 전개

# 5단계 빅데이터 분석 방법론 플로우
[1단계] 분석 기획
- 비즈니스 이해 및 범위 설정
- 프로젝트 정의 및 계획 수립
- 프로젝트 위험 계획 수립 → 예상되는 위험으로부터 ‘회피, 전이, 완화, 수용’


[2단계] 데이터 준비
- 필요 데이터 정의
- 데이터 스토어 설계
- 데이터 수집 및 정합성 검정


[3단계] 데이터 분석
- 분석용 데이터 준비
- 텍스트 분석
- 탐색적 분석
- 모델링
- 모델 평가 및 검증

  
[4단계] 시스템 구현
- 설계 및 구현
- 시스템 테스트 및 운영

  
[5단계] 평가 및 전개
- 모델 발전 계획
- 프로젝트 평가 및 보고
