## Day 2

# 빅데이터 가치 산정이 어려운 이유
- 데이터 활용 방식 = 특정 데이터를 누가, 언제, 어떻게, 어디서 활용하는지 알 수 없음
- 가치 창출 방식 = 기존에 없던 새로운 가치를 창출
- 분석 기술의 발전 = 가치 있는 데이터와 가치 없는 데이터의 경계를 나누기 어려움

# 미래의 빅데이터 활용에 필요한 3요소
- 데이터 = 모든 것의 데이터화
- 기술 = 진화하는 알고리즘, 인공지능
- 인력 = 데이터 사이언티스트, 알고리즈미스트

# 7가지 빅데이터 활용 기본 테크닉
- 연관규칙 학습 = 상관 관계를 찾는 방법 (연관 분석, 장바구니 분석)
- 유형분석 = 새로운 사건이 속할 범주를 찾는 방법 (분류)
- 유전 알고리즘 = 최적화가 필요한 문제의 해결책을 점진적으로 진화 (최적화)
- 기계학습, 머신러닝 = 데이터로부터 규칙을 찾고 규칙을 활용해 예측
- 회귀분석 = 수치로 이루어진 두 변인의 관계를 파악
- 감정 분석 = 감정을 분석하는 방법
- 소셜 네트워크 분석 = 영향력 있는 사람을 찾아냄. 소셜 관계 파악

# 빅데이터의 위기 요인과 통제 방안
- 사생활 침해 (빅브라더, 빈집털이, 사용자 행동 패턴 예측) → 동의에서 책임으로
- 책임 원칙 훼손 (마이너리티 리퐅, 신용카드 발급 여부 판단, 범죄 발생 이전에 체포) → 결과 기반 책임 원칙 고수
- 데이터 오용 (비행기 탑승 금지자 목록에 상원 의원 포함 오류사례 있음) → 알고리즘 접근 허용

  @ 알고리즈미스트(Algorithmist) = 알고리즘을 이해하고 해석함으로써 사전에 피해자를 방지하고 구제하는 전문인력

# 개인정보 비식별 기술
-   데이터 마스킹 = 기존 형식을 유지한 채 식별할 수 없는 값으로 대체 (송우람 → 송**)
-   가명 처리 = 데이터의 값을 다른 값으로 변경 (홍길동 → 임꺽정)
-   총계 처리 = 전체 데이터에 대한 총합 또는 평균 (70점, 80점, 90점 → 평균 80점)
-   데이터 값 삭제 = 데이터 값의 일부를 삭제 (서울시 서초구 → 서울시)
-   데이터 범주화 = 특정 값이 아닌 범위를 제공 ( 80점 → 70~90점 사이)

# 빅데이터 분석의 핵심은 크기가 아니라 인사이트
- 데이터는 크기가 아닌 데이터로부터 어떤 시각과 인사이트를 얻을 수 있느냐의 문제
- 비즈니스 핵심 가치에 집중하고 이와 관련된 분석 평가지표를 개발 → 효과적으로 시장과 고객의 변화에 대응할 수 있을 때 가치가 있음
- 걸림돌은 비용이 아닌 분석적 방법과 성과에 대한 이해 부족

# 일차원적 분석(산업별)
- 금융 서비스 = 신용점수 산정, 사기 탐지, 가격 책정, 프로그램 트레이딩, 클레임 분석, 고객 수익성 분석
- 에너지 = 트레이딩, 공급/수요 예측
- 병원 = 가격 책정, 고객 로열티, 수익 관리
- 정부 = 사기 탐지, 사례 관리, 범죄 방지, 수익 최적화

# 데이터 사이언스 구성 요소
- Analytics = 수학, 확률 모델, 머신러닝, 분석학, 패턴, 인식과 학습, 불확실성 모델링 등
- IT(Data Management) = 시그널 프로세싱, 프로그래밍, 데이터 엔지니어링, 데이터 웨어하우징, 고성능 컴퓨터 등
- 비즈니스 분석 = 사기 탐지, 사례 관리, 범죄 방지, 수익 최적화

# 데이터 사이언티스트에게 요구되는 역량
- 하드 스킬 = 빅데이터에 대한 이론적 지식, 분석 기술에 대한 숙련
- 소프트 스킬 = 통찰력 있는 분석, 설득력 있는 전달, 다분야 간 협력

# 가트너가 제시한 데이터 사이언티스트 요구 역량
- 데이터 관리 = 데이터에 대한 이해
- 분석 모델링 = 분석론에 대한 지식
- 비즈니스 분석 = 비즈니스 요소에 초점
- 소프트 스킬 = 커뮤니케이션, 협력, 리더쉽, 창의력, 규율, 열정

# 전략과 인사이트 도출을 위한 인문학
- 경영전략을 수립하는 데는 소프트 스킬이 필요
- 비즈니스 핵심가치를 이해하고 고객과 직원의 내면적 요구를 이해하는 능력 요구
